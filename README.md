# 🌟 Overview

Movie Recommender System is a powerful AI-based web application built using **Python, Streamlit, Machine Learning, and NLP**.

The application recommends movies similar to the user's selected movie using **Content-Based Filtering** and **Cosine Similarity** algorithms.

The project provides a beautiful Netflix-inspired interface with interactive movie recommendations and real-time movie details.
